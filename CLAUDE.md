## DOCS FOLLOW CODE

DOCS FOLLOW CODE: any change to user-facing behavior, CLI flags, inputs, or capabilities MUST update the docs that describe it (README, QUICKSTART, CLI_ORIENTATION, docs/*) in the SAME branch. A behavior change with stale docs is an incomplete change — do not defer doc updates.
